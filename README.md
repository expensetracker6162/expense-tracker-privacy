# Expense Tracker — Privacy Policy

Public privacy policy page for the **Expense Tracker** Android app
(`com.ammrwahab.expensetracker`), published with GitHub Pages for the Google Play
store listing.

- **Policy page:** `index.html` (single self-contained file, no external fonts,
  scripts, analytics or cookies)
- **App behavior it documents:** expenses stored locally in app-private storage,
  no account, no networking, no third-party SDKs, no Android permissions

## Hosting

GitHub Pages serves this repository from the `main` branch, repository root.

## Editing

`index.html` is the only page and has no build step. Any change to the app's data
handling must be reflected here, and the "Last updated" date in the page must be
bumped at the same time.
